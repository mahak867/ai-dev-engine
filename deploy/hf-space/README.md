# APEX Society — live demo

A 9-agent software team (Planner, Architect, Coder, Reviewer, SelfHealer,
Debugger, Executor, DocWriter, Memory) that plans, writes, reviews and repairs
a project while you watch.

- **Demo replay** (default, no key): runs the real pipeline with canned agent
  outputs, so you can see the agents hand work to each other. No LLM is called.
- **Real run**: paste your own Groq (free tier), OpenRouter or Qwen key. It is
  used for your run only and never stored. Download the result as a ZIP.

Source, eval harness and MCP server: https://github.com/mahak867/ai-dev-engine
